高考录取分数线数据获取方案

一、数据源分析（优先级排序）

第一梯队：官方免费数据源

数据源 网址 覆盖范围 优点 缺点
阳光高考网 https://gaokao.chsi.com.cn/ 全国 教育部官方、权威 数据分散、需逐校查询
各省教育考试院 各省官网 本省 最准确、最及时 31 个省份、格式不一
高校招生网 各校官网 本校 官方数据、详细 分散、需逐个访问

第二梯队：补充数据源

数据源 优点 缺点
中国教育在线 数据较全 部分需付费
高考直通车 整理较好 非官方
各高考志愿 APP 数据全 需注册/付费

二、数据表结构设计

主表：高校录取分数线大宽表

字段名 类型 说明 必填
school_code string 学校代码 ✓
school_name string 学校名称 ✓
province_code string 省份代码 ✓
province_name string 省份名称 ✓
year int 年份 (2018-2025) ✓
category string 科类 (物理/历史/理科/文科) ✓
batch string 批次 (一本/二本/本科批) ✓

data_source string 数据来源 ✓
update_time datetime 更新时间 ✓

维度表

1. 高校维度表 (school_dim) - school_code, school_name, province, type_985, type_211, type_double_first_class

2. 省份维度表 (province_dim) - province_code, province_name, region (华北/华东等)

3. 年份维度表 (year_dim) - year, gaokao_type (老高考/新高考)

4. 科类维度表 (category_dim) - category_code, category_name, applicable_provinces

5. 批次线表 (batch_score) ← 新增 | 字段 | 说明 | |------|------| | year | 年份 | | province_code | 省份代码 | | category | 科类 | | batch_name | 批次名 (本科一批/本科二批/专科批等) | | min_score | 批次最低控制线 |

三、数据获取逻辑

核心流程

开始
  ↓
遍历高校名单 (147 所)
  ↓
遍历年份 (2018-2025)
  ↓
遍历省份 (31 个)
  ↓
遍历科类 (物理/历史 或 理/文)
  ↓
查询录取分数线
  ↓
记录数据 (即使为空)
  ↓
完成

伪代码

# 完整的数据获取框架
schools = load_school_list()  # 147 所高校
provinces = load_province_list()  # 31 个省份
years = range(2018, 2026)  # 2018-2025
categories = ['物理类', '历史类']  # 或 ['理科', '文科']

for school in schools:
    for year in years:
        for province in provinces:
            for category in categories:
                # 第一步：获取该省该年的批次线（省控线）
                batch_scores = fetch_province_batch_scores(year, province, category)

                for batch in batch_scores:  # 一本/二本/本科批等
                    record = {
                        'school_code': school.code,
                        'school_name': school.name,
                        'province_code': province.code,
                        'province_name': province.name,
                        'year': year,
                        'category': category,
                        'batch': batch.name,
                        'province_batch_score': batch.score,  # 省控线
                        'min_score': None,  # 即使为空也记录
                        'score_diff': None,  # 线差 = 录取分 - 省控线
                        'min_rank': None,   # 位次
                        'data_source': '阳光高考网',
                        'update_time': now(),
                        'is_complete': False
                    }

                    # 第二步：尝试获取该校在该省该批次的录取数据
                    score_data = fetch_school_score(school, year, province, category, batch)
                    if score_data:
                        record.update(score_data)
                        record['score_diff'] = score_data['min_score'] - batch.score
                        record['is_complete'] = True

                    # 保存记录（保证维度完备）
                    save_record(record)

四、缺失数据处理策略

1. 结构性缺失（合理缺失）

情况 说明 处理方式
新高考改革前 2020 年前无物理/历史类 记录为空，标记原因
学校未在该省招生 某些学校不在某些省份招生 记录为空，标记"未招生"
批次合并 一二本合并为本科批 记录 batch 为"本科批"

2. 数据缺失（需补充）

情况 处理方式
官方未公布 标记为"待补充"，后续找其他数据源
数据不完整 有多少记多少，缺失字段为空
数据冲突 以阳光高考网为准，其他为参考

九、关键数据说明

1. 省控线（批次线）

定义：各省教育考试院划定的各批次最低控制分数线

示例：

2025 年 江苏省 物理类 本科批 省控线：450 分
2025 年 江苏省 物理类 特殊类型招生控制线：520 分（原一本线）

重要性： - 计算"线差"的基础（线差 = 录取分 - 省控线） - 消除各省试卷难度差异的影响 - 便于跨年度、跨省份比较

2. 位次（排名）

定义：考生分数在全省的排名位置

示例：

清华大学 2025 年 江苏省 物理类 最低录取位次：前 100 名
北京大学 2025 年 江苏省 物理类 最低录取位次：前 200 名

重要性： - 比分数更稳定（不受试卷难度影响） - 填报志愿的核心参考指标 - 便于做年度对比分析

3. 线差

公式：线差 = 高校录取分 - 省控线

示例：

省控线：500 分
清华录取分：680 分
线差 = 680 - 500 = 180 分

用途： - 消除批次线波动影响 - 更准确评估学校录取难度
